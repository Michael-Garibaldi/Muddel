# Muddel
Muddel is an emacs mud client 


It features :

*  Ansi Color compatibility

  Right now it's in pre-alpha, so it's rough, but it's one file. Just place it into your Emacs/(version)/lisp/play area , restart Emacs and call it
  by typing in (require 'Simple_Mud_Client).

  The Mud it logs into can be configured on top, just change the existing mud  to yours and you're ready to go.
